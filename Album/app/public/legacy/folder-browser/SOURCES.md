## Written from scratch

Nothing usable was found for these, so they were written by hand in the style of the author's `maplelake/handwritten/script.js`:

- `open()` / `finish()` / `loadFolder()` / `render()` / `renderCrumbs()` / `renderCount()` / `showStatus()` / `setBusy()`: the glue that connects the pieces above to `GET /api/imports/folders` and to the `open({ startPath, onSelect, onCancel })` API.
- Using a native `<dialog>` with `showModal()` instead of an overlay `div` (none of the small modal projects found do this; they all predate wide `<dialog>` support).
- The breadcrumb rendering (turning the crumb objects from #8 into buttons and separators).
- The image-count line and the supported-types note.
- The small-screen `@media` block in `Responsive.css` and the dark-theme safety rules (`background`, `color`, `color-scheme: light` on the dialog).
- `demo.html`.

## Looked at but not used

- `Tangchunhai/modal` `_keypress` (Escape via `document` `keydown` and `keyCode === 27`): not needed, because a modal `<dialog>` already turns Escape into a `cancel` event sent only to the top-most dialog.
- `AmraniCh/vanilla-filemanager` `src/js/components/modal.js` and `files-table.js`: an overlay `div` modal and a static table with selection logic; the project is a template with no data loading, so nothing else fitted.
- The cnblogs file-explorer's `processHandle` / File System Access API approach: it reads folders in the browser, but this app must list folders on the server machine.
